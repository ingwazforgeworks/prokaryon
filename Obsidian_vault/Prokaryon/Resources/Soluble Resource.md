**Type note:** Soluble Resource  
**Status:** Proposed

A resource dissolved in the water, able to diffuse, be carried by [[Flow]], and cross a membrane through a transporter. Anything soluble is contestable: it moves, so a cell cannot own it, only reach it first.

### Properties every soluble resource has

| Property | Consequence |
|---|---|
| Diffuses | Concentrations even out, so hoarding is impossible |
| Advected by [[Flow]] | Position in the current determines supply |
| Decays or is consumed | Requires a source to persist |
| Needs a transporter | Each one costs a gene — see [[Naming Conventions]] on the permease-per-resource rule |

### Contrast
Compare [[Insoluble Resource]], which cannot move or be imported and must be attacked where it lies. The pairing of each soluble fuel with an insoluble stock is set out in [[Naming Conventions]].

Specification §7.1 calls for a small set of advected, diffusing pools rather than a full chemistry model. The [[Resource Index]] holds the conservation rule requiring every pool to have explicit sources and sinks.
